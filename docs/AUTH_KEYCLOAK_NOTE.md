## 2. Thông số Realm & Client cho ứng dụng Web React (FE) & NestJS (BE)

| Thuộc tính | Giá trị cấu hình | Ghi chú |
| :--- | :--- | :--- |
| **URL (Authority)** | `http://localhost/auth` (hoặc `http://localhost:8082`) | URL gốc của Keycloak |
| **Realm** | `minicloud` | Realm chứa user của app |
| **Client ID** | `web-frontend` | Client dạng Public (PKCE S256) |
| **User Self-Registration (`A1`)** | `registrationAllowed: true` | Đã bật trong `minicloud-realm.json` |
| **Valid Redirect URIs** | `http://localhost/*`, `http://localhost:8080/*`, `http://localhost:5173/*` | Cho phép callback về FE |
| **Web Origins** | `http://localhost`, `http://localhost:8080`, `http://localhost:5173` | Tránh lỗi CORS |
| **Issuer (`iss` trong JWT - `A3`)** | `http://localhost/auth/realms/minicloud` | Dùng khi NestJS verify token |
| **JWKS URI nội bộ (`A3`)** | `http://authentication-identity-server:8080/realms/minicloud/protocol/openid-connect/certs` | NestJS container gọi trực tiếp qua `cloud-net` |
| **JWKS URI qua Proxy (`A3`)** | `http://localhost/auth/realms/minicloud/protocol/openid-connect/certs` | Kiểm tra từ máy host |

### Bật `registrationAllowed=true` trên volume Keycloak cũ (không cần xóa volume)
File `authentication-identity-server/realm/minicloud-realm.json` đã bật `"registrationAllowed": true`. Nếu container Keycloak đang dùng volume `keycloak_data` tạo từ trước (Keycloak không tự ghi đè realm đã tồn tại khi `--import-realm`), chạy 1 lệnh sau để bật ngay `registrationAllowed=true` và tạo sẵn user `student_demo` / `123456`:
- **macOS / Linux / Git Bash:** `bash authentication-identity-server/enable-register.sh`
- **Windows PowerShell:** `.\authentication-identity-server\enable-register.ps1`

## 4. Flow tích hợp cho Hân ở Frontend (Login + Register `A1`)

1. **Đăng nhập (`/login`):**
   - Gọi `keycloak.login({ redirectUri })` (hàm `loginWithKeycloak(redirect)` hiện có).
2. **Đăng ký (`/register` — `A1`):**
   - Realm `minicloud` đã bật `registrationAllowed: true`.
   - Trong `keycloak.ts`, thêm hàm gọi `client.register({ redirectUri: new URL(safeRedirect(path), window.location.origin).href })` (hoặc chuyển tới endpoint `/protocol/openid-connect/registrations`).
   - Sau khi user điền form đăng ký của Keycloak, Keycloak tự động đăng nhập và redirect về `redirectUri` trên MiniHome.

## 5. Schema PostgreSQL cho Vân & Hân (`A2` Bookings & `A5` Rooms Filter)

File `relational-database-server/init/001_schema.sql` (cho volume mới) và `relational-database-server/init/004_parity_rooms_bookings.sql` (migration idempotent cho volume đang chạy) đã chuẩn bị đầy đủ:

### 5.1. Bảng `rooms` (đủ 8 phòng + đầy đủ cột cho bộ lọc FE `A5`)
- **Các cột:**
  - Cơ bản: `id`, `title`, `address`, `price` (`BIGINT`), `area` (`NUMERIC(8,2)`), `description`, `image_url`
  - Mở rộng cho filter FE (`A5`):
    - `district TEXT` (`'Quận 7'`, `'Bình Thạnh'`, `'Thủ Đức'`, `'Quận 3'`, `'Quận 5'`)
    - `type TEXT` (`'Studio'`, `'Có gác'`, `'Phòng trọ'`)
    - `amenities TEXT[]` (VD: `ARRAY['Nội thất', 'Máy lạnh', 'Wifi', 'Bếp riêng']` — driver `pg` tự parse thành `string[]`)
    - `available BOOLEAN` (7 phòng `true`, phòng 6 `false`)
    - `images TEXT[]` (danh sách URL ảnh gallery trên MinIO — driver `pg` tự parse thành `string[]`)
- **Câu query gợi ý cho Vân trong `app.service.ts`:**
  ```sql
  SELECT id, title, address, district, price, area, type, amenities, available, description, image_url, images
  FROM rooms
  ORDER BY id;
  ```

### 5.2. Bảng `bookings` (`A2` — Đặt lịch hẹn xem phòng)
- **Định nghĩa bảng:**
  ```sql
  CREATE TABLE IF NOT EXISTS bookings (
      id          BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
      room_id     BIGINT NOT NULL REFERENCES rooms(id) ON DELETE CASCADE,
      user_id     TEXT,
      user_email  TEXT,
      name        TEXT NOT NULL DEFAULT '',
      phone       TEXT NOT NULL DEFAULT '',
      visit_date  TEXT NOT NULL DEFAULT '',
      note        TEXT NOT NULL DEFAULT '',
      status      TEXT NOT NULL DEFAULT 'pending',
      created_at  TIMESTAMPTZ NOT NULL DEFAULT NOW()
  );
  ```
- Đã có sẵn 1 bản ghi mẫu (`id = 1`, `room_id = 1`, `user_id = 'student_demo'`, `name = 'Nguyen A'`, `phone = '0901234567'`, `visit_date = '2026-11-10'`).
- `visit_date` để kiểu `TEXT` để chấp nhận linh hoạt cả định dạng `DD/MM/YYYY` lẫn ISO `YYYY-MM-DD` từ DatePicker của FE mà không lỗi parse ngày.
