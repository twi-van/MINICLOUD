# A2 — Booking / hẹn xem phòng: hướng dẫn tự làm

## 0. Ai làm gì?

| Người | Việc |
| ----- | ---- |
| **Vân (bạn)** | Bảng `bookings` + `POST /api/bookings` (+ JWT Guard A3) + proxy nginx |
| **Hân** | Bật nút/form khi `dataSource === 'api'`, gọi API kèm Bearer (không đổi layout lớn) |
| **Lợi** (tuỳ) | Có thể giúp file SQL init nếu nhóm thống nhất |

**Acceptance:** sau login → gửi lịch hẹn → **lưu Postgres**; không token → **401**.

A3 đã xong → A2 **tái sử dụng** `JwtAuthGuard`, không viết verify JWT lại.

---

## 1. Luồng (hiểu rồi mới code)

```
User login Keycloak
  → mở chi tiết phòng → form (name, phone, date)
  → FE POST /api/bookings + Authorization: Bearer …
  → nginx → Nest JwtAuthGuard
  → INSERT bookings (user_sub từ token + room_id + …)
  → 201 + JSON booking
```

FE hiện tại (`RoomDetailPage.tsx`):

- Mode **mock**: nút “Hẹn xem phòng” bật, nhưng **không gọi API** (chỉ `setSubmitted(true)`).
- Mode **api**: nút đang **disabled** (“Chưa có dịch vụ đặt lịch”) → Hân sẽ bật sau khi bạn có API.

Contract form FE (thống nhất với Hân):

| Field form | Gợi ý JSON body |
| ---------- | ---------------- |
| (từ URL) room id | `roomId` (number) |
| name | `guestName` |
| phone | `phone` |
| date | `visitDate` (ISO `YYYY-MM-DD`) |
| (từ JWT) | `userSub` = `req.user.sub` — **không** tin client gửi sub |

### Bước 1 — Bảng Postgres

Thêm file mới (không sửa lung tung seed cũ nếu nhóm đang dùng volume):

`relational-database-server/init/004_bookings.sql`

```sql
CREATE TABLE IF NOT EXISTS bookings (
    id           BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    room_id      BIGINT NOT NULL REFERENCES rooms(id),
    user_sub     TEXT NOT NULL,          -- Keycloak subject (JWT.sub)
    guest_name   TEXT NOT NULL,
    phone        TEXT NOT NULL,
    visit_date   DATE NOT NULL,
    created_at   TIMESTAMPTZ NOT NULL DEFAULT NOW()

CREATE INDEX IF NOT EXISTS idx_bookings_user_sub ON bookings(user_sub);
```

**Lưu ý volume:** script trong `init/` chỉ chạy khi **volume Postgres mới**.

### Bước 2 — Service: INSERT

Trong `app.service.ts` (đã có `getPool()` — tái dùng):

```ts
async createBooking(input: {
  roomId: number;
  userSub: string;
  guestName: string;
  phone: string;
  visitDate: string; // 'YYYY-MM-DD'
}) {
  const pool = this.getPool();
  if (!pool) {
    throw new ServiceUnavailableException('Database chưa cấu hình');
  }

  // (tuỳ chọn) kiểm tra room tồn tại
  const room = await pool.query(`SELECT id FROM rooms WHERE id = $1`, [input.roomId]);
  if (room.rowCount === 0) {
    throw new NotFoundException(`Room ${input.roomId} not found`);
  }

  const result = await pool.query(
    `INSERT INTO bookings (room_id, user_sub, guest_name, phone, visit_date)
     VALUES ($1, $2, $3, $4, $5::date)
     RETURNING id, room_id, user_sub, guest_name, phone, visit_date, created_at`,
    [input.roomId, input.userSub, input.guestName, input.phone, input.visitDate],
  );

  const row = result.rows[0];
  return {
    id: Number(row.id),
    roomId: Number(row.room_id),
    userSub: row.user_sub,
    guestName: row.guest_name,
    phone: row.phone,
    visitDate: row.visit_date,
    createdAt: row.created_at,
  };
}
```

Import thêm `ServiceUnavailableException` nếu dùng.

### Bước 3 — Controller: POST + Guard

Trong `app.controller.ts`:

```ts
import { Body, Post, /* ... */ } from '@nestjs/common';

@Post('bookings')
@UseGuards(JwtAuthGuard)
createBooking(
  @Req() req: { user?: Record<string, unknown> },
  @Body()
  body: {
    roomId?: number;
    guestName?: string;
    phone?: string;
    visitDate?: string;
  },
) {
  const userSub = String(req.user?.sub ?? '');
  if (!userSub) {
    throw new UnauthorizedException('Token thiếu sub');
  }
  if (!body.roomId || !body.guestName || !body.phone || !body.visitDate) {
    throw new BadRequestException('Thiếu roomId / guestName / phone / visitDate');
  }
  return this.appService.createBooking({
    roomId: Number(body.roomId),
    userSub,
    guestName: body.guestName.trim(),
    phone: body.phone.trim(),
    visitDate: body.visitDate,
  });
}
```

(Import `BadRequestException`, `UnauthorizedException` khi cần.)

**Tuỳ chọn:** `GET /bookings` (cũng Guard) — list booking của `req.user.sub` — tiện demo Word, không bắt buộc đề.

### Bước 4 — Proxy nginx

`api-gateway-proxy-server/nginx.conf` — **Cách A** (giống `/api/me`): thêm **trước** `location /`:

```nginx
# A2 — POST /api/bookings (JWT bắt buộc)
location = /api/bookings {
  proxy_pass http://app_backend/bookings;
  proxy_set_header Host $host;
  proxy_set_header Authorization $http_authorization;
  proxy_set_header X-Real-IP $remote_addr;
  proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
  proxy_set_header X-Forwarded-Proto $scheme;
}
```

**Nhớ** forward `Authorization` — không có thì Guard luôn 401 dù FE đã login.

## 3. Việc của Hân (bạn chỉ cần nhắn contract)

File: `web-frontend-server/src/features/rooms/pages/RoomDetailPage.tsx`

1. Bỏ `disabled` khi `config.dataSource === 'api'` (vẫn disable nếu `available === false`).
2. Thêm `postJson` trong `http.ts` (giống `getJson`, method POST + body + Bearer).

4. Thành công → Result “Đã gửi lịch hẹn”; 401 → bảo user login.

Bạn **không** cần sửa UI Airbnb — giữ MiniHome.

## 4. Sai thường gặp

| Triệu chứng | Nguyên nhân |
| ----------- | ----------- |
| 404 từ nginx | Thiếu `location = /api/bookings` hoặc để sau `location /` nuốt path |
| 401 dù đã login | Proxy không `proxy_set_header Authorization` |
| 500 / relation bookings does not exist | Chưa chạy SQL trên volume hiện tại |
| 503 Database | App thiếu `POSTGRES_*` (compose đã có — kiểm tra container) |
| Insert OK nhưng FE vẫn “Chưa có dịch vụ” | Phần Hân chưa bật nút mode api |

## 5. Thứ tự gợi ý tự làm (1 buổi)

1. SQL `bookings` (exec psql cho chắc).
2. `createBooking` trong service.
3. `POST bookings` + `@UseGuards(JwtAuthGuard)`.
4. nginx location + rebuild proxy + app.
5. curl 401 / 200.
6. Nhắn Hân contract JSON + bật form.
7. Demo web: login → chi tiết phòng → hẹn → xem row trong `psql`.
